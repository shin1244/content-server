# Bot Client (부하 테스트용 봇)

`content-server` 에 다수의 가짜 유저를 붙여 채팅/친구 기능에 부하를 주는 테스트 클라이언트.
표준 라이브러리만 사용한다 (외부 의존성 없음).

## 빌드 / 실행

```
cd bot
go build -o bot.exe .
./bot.exe -n 100 -interval 1s
```

## 동작

1. `user001` ~ `userNNN` 이름으로 각각 TCP 접속 후 `/n <name>` 으로 로그인
2. 이후 `interval` (0.5x~1.5x 지터) 마다 행동 하나를 고른다
   - **90%** 전체 채팅 : 단어 풀에서 1~12개를 무작위로 뽑아 전송
   - **10%** 친구 명령 :

| 명령 | 가중치 | 설명 |
|---|---|---|
| `/f add <name>` | 3 | 자기 자신을 제외한 무작위 유저에게 친구 요청 |
| `/f list` | 3 | 친구 목록 확인 → **Request 섹션을 파싱해 대기 목록에 저장** |
| `/f <text>` | 2 | 친구 전체 채팅 |
| `/f accept <name>` | 3 | 대기 목록에서 무작위로 수락 (list 를 본 뒤에만 선택됨) |
| `/f reject <name>` | 1 | 대기 목록에서 무작위로 거절 (list 를 본 뒤에만 선택됨) |

`accept` / `reject` 는 **`/f list` 응답을 받아 대기 목록이 채워진 뒤에만** 후보에 오른다.
한 번 쓴 이름은 목록에서 빼고, 다음 `/f list` 때 다시 채운다.

## 옵션

| 플래그 | 기본값 | 설명 |
|---|---|---|
| `-addr` | `127.0.0.1:5050` | 서버 주소 |
| `-n` | `10` | 봇 수 |
| `-start` | `1` | 이름 시작 번호 (`user001` 의 `1`) |
| `-prefix` | `user` | 이름 접두사 (전체 길이는 3~9자여야 함) |
| `-chat-rate` | `0.9` | 전체 채팅 확률, 나머지는 친구 명령 |
| `-interval` | `1s` | 봇 한 마리의 평균 행동 간격 |
| `-ramp` | `20ms` | 봇 접속 간격 (0 이면 동시 접속) |
| `-login-wait` | `500ms` | 로그인 후 첫 행동까지 대기 |
| `-duration` | `0` | 실행 시간 (0 이면 Ctrl+C 까지) |
| `-stat` | `5s` | 통계 출력 주기 (0 이면 끔) |
| `-seed` | `0` | 난수 시드 (0 이면 현재 시각, 값을 주면 재현 가능) |
| `-v` | `false` | 주고받는 메시지 전부 출력 |

여러 대의 PC/프로세스로 나눠 돌릴 때는 `-start` 로 이름 구간을 겹치지 않게 나눈다.

```
./bot.exe -n 100 -start 1      # user001 ~ user100
./bot.exe -n 100 -start 101    # user101 ~ user200
```

## 주의

- 서버는 닉네임을 **3자 이상 10자 미만**으로 제한한다 (`Consumer::HandleNick`).
  `-prefix` 를 바꾸면 이름 길이가 범위를 벗어나지 않는지 확인할 것 (실행 시 검증함).
- 페이로드 상한은 256바이트다 (`Protocol.h` 의 `char message[256]`).
  `/f list` 응답이 이 크기에서 잘리므로, 봇은 꽉 찬 응답의 마지막 줄을 버리고 파싱한다.
- 채팅 1회마다 서버가 골드 지급 + 1/50 확률로 아이템 드랍(DB write)을 한다.
  `-interval` 을 줄이면 DB 부하가 그대로 올라간다.
